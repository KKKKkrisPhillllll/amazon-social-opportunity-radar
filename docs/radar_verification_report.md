## 凭据与样例边界

## 研究层回归护栏

- 评分护栏：执行画像、旅程和机会门槛后，原机会的 `score_breakdown` 与 `total_score` 保持不变。
- 候选护栏：研究层只处理总分至少 60 且通过门槛的机会，并按配置限制每日报告至多 3 个。CLI 日报在 Gate 不合格时不渲染画像/旅程章节。
- 证据护栏：低置信度是 persona/journey builder 在证据不足时返回的结构化结果；未观察到的旅程阶段标为待后续采集验证。
- 隐私护栏：画像证据仅包含 `platform`、`url`、`summary`，不包含作者、账号、用户 ID、邮箱或评论正文等个人身份字段。

样例 CLI 报告包含 1 个机会、1 条公开 URL、0 个画像/旅程。该机会总分 73，但由于不满足至少 2 条证据和 2 个独立来源的 Gate，CLI 日报不渲染画像/旅程章节或 Mermaid 图。这是预期行为，不是把 builder 的低置信度结构化结果误写为已出现在样例日报中。低置信度与待验证文案由全量测试中的单证据画像/旅程 builder 场景覆盖并通过。
